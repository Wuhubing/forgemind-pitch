# ForgeMind · VentureWest Pitch

**Mechanical designs, verified before delivery.**
AutoMech is an AI agent that turns a plain-English goal into CAD, then proves the machine works in physics simulation.

- **Slides (live):** https://wuhubing.github.io/forgemind-pitch/
- **Pitch script (English + 中文):** [script.md](script.md)
- **Product source:** https://github.com/OliviaLJY/AutoMech

## Presenting

Open the slides link and use:

| Key | Action |
|---|---|
| → / Space / click right side | Next slide |
| ← / click left side | Previous slide |
| F | Full screen |
| N | Show or hide the speaker notes |

Link to a specific slide with `#N`, for example `…/forgemind-pitch/#4`.

## Files

- `index.html`: the whole deck in a single page, with no build step
- `assets/`: simulation animations of the four-planet reducer and the slider-crank
- `script.md`: the 5-minute script, slide by slide
